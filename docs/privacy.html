개인정보처리방침

웹 타임머신 (Web Time Machine) · 시행일: 2026-11-15

1. 수집하는 개인정보

웹 타임머신은 어떠한 개인정보도 수집·저장·판매·공유하지 않습니다. 분석 도구, 광고, 추적기를 포함하지 않습니다.

2. 로컬 저장

레트로 스킨 켜짐/꺼짐 설정 하나만 사용자 브라우저의 chrome.storage.local에 저장됩니다. 이 값은 브라우저 밖으로 전송되지 않습니다.

3. 현재 탭 주소의 처리

사용자가 팝업에서 과거로 이동 버튼을 클릭한 경우에 한해, 현재 탭의 URL이 Wayback Machine(archive.org

4. 제3자 서비스

아카이브 콘텐츠는 Internet Archive의 Wayback Machine에서 제공받습니다. 아카이브 페이지 로딩 시 해당 서비스의 정책이 적용됩니다. (archive.org 이용약관)

5. 권한 사용 사유

  • activeTab — 사용자가 클릭한 현재 탭의 주소를 읽어 이동할 사이트를 확인합니다.
  • storage — 스킨 설정을 로컬에 저장합니다.
  • archive.org / web.archive.org 호스트 권한 — 스냅샷 조회 및 아카이브 페이지 표시에만 사용합니다.
